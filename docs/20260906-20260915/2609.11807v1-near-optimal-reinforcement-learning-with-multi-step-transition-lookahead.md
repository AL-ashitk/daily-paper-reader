## 摘要
我们研究带有转移前瞻的强化学习（RL），其中智能体在决定行动方案之前，可以观察到执行任意长度为 ℓ 的动作序列后将会访问哪些状态。尽管前瞻能够显著提升可达到的性能，但已知多步转移前瞻下的最优规划是 NP 难的，然而这一困难性是在折扣因子任意接近 1 的情况下建立的。因此，此前尚不清楚对于任意折扣因子该问题是否仍然困难，以及是否仍能高效地进行近最优规划。我们解决了这两个问题。首先，我们证明对于每个固定的有理折扣因子（γ∈(0,1)），精确规划仍然是 NP 难的。其次，我们为每个固定的前瞻深度引入了一种随机多项式时间近似方案。随后，我们利用乐观主义和方差自适应置信界，将该方法扩展到未知转移和随机奖励情形。所得算法实现的累积遗憾，其主导项与经典表格型折扣强化学习相匹配，仅相差对数因子。因此，尽管带有转移前瞻的精确规划是 NP 难的，高效的近最优规划与学习仍然是可能的。

## Abstract
We study reinforcement learning (RL) with transition look-ahead, where the agent may observe which states would be visited upon playing any sequence of $\ell$ actions before deciding its course of action. Although look-ahead can substantially improve achievable performance, it is known that optimal planning with multi-step transition look-ahead is NP-hard, but this hardness was established using discount factors arbitrarily close to one. It was therefore unknown whether the problem remains hard for any discount factor, and whether near-optimal planning can nevertheless be performed efficiently. We resolve both questions. First, we show that for every fixed rational discount factor ($γ\in(0,1)$), exact planning remains NP-hard. Second, we introduce a randomized polynomial-time approximation scheme for every fixed look-ahead depth. We then extend our approach to unknown transitions and stochastic rewards using optimism and variance-adaptive confidence bounds. The resulting algorithm achieves cumulative regret whose leading term matches classical tabular discounted RL up to logarithmic factors. Thus, although exact planning with transition look-ahead is NP-hard, efficient near-optimal planning and learning remain possible.

## 1. 核心问题与整体含义

- **研究背景**：标准强化学习（RL）中，智能体只有在执行动作之后才能观察到奖励和下一状态。本文研究**带转移前瞻（transition look-ahead）**的 RL：在决策前，智能体可观测到执行任意长度为 ℓ 的动作序列后将访问哪些状态，即获得一个深度为 ℓ 的完整转移树 `C_ℓ^t = (Θ_t, ..., Θ_{t+ℓ-1})`。这一设定刻画了诸如实时交通导航（Waze/Coyote）、高保真昂贵仿真器按需查询、供应链到货时间预测等"特权信息"场景。
- **理论背景**：已有工作（Pla et al., 2026a）证明：ℓ=1 时规划可多项式求解，但 ℓ≥2 时精确规划是 NP 难的。然而该困难性证明**依赖折扣因子 γ 任意接近 1**。
- **两个开放问题**：
  1. 对任意固定的折扣因子 γ∈(0,1)，精确规划是否仍然 NP 难？
  2. 尽管精确规划困难，能否**高效地实现近最优规划与学习**？
- **整体含义**：论文同时解决了上述两个问题，结论是——精确规划对任意固定有理折扣因子都 NP 难，但存在随机多项式时间近似方案（RPTAS），并且学习算法的遗憾主项与经典表格型折扣 RL 只差对数因子。这揭示"由前瞻导致的指数级增广状态空间"本身并不妨碍高效的近似控制。

## 2. 方法论

### 2.1 问题形式化
- 将前瞻问题嵌入标准折扣 MDP 框架：增广状态空间为 `S × Ω^ℓ`，其中 `Ω = S^{S×A}` 是转移表空间，`Q` 为乘积分布。
- 定义增广 MDP 的 Bellman 最优算子 `T_ℓ`，其为 γ-压缩，`V*_ℓ` 为其唯一不动点；最优策略为 `argmax_a Q*_ℓ(s, θ_0,...,θ_{ℓ-1}, a)`。

### 2.2 困难性结果（Theorem 1）
- **结论**：对每个整数 ℓ≥2 和每个固定有理折扣因子 γ∈(0,1)，判定是否存在前瞻策略使 `v^π_ℓ(s_0) ≥ θ` 是 NP 难的。
- **核心技巧**：在 Pla et al. (2026a) 的归约基础上（基于 Mehta et al. (2020) 的"期望最大值间隙"构造），从 INDEPENDENT SET 归约。关键修改是给等待动作赋予奖励 `b = (1-γ)T`（其中 `T = γ^{ℓ+1}U`），使得 `(1-γ)T + γT = T`，即 T 成为"等待"的不动点。这样当所有候选子集的期望最大值 ≤U 时，承诺与等待都不超过 T；而当存在满足 `E[max_{v∈S*} Y_v] ≥ U+Δ` 的独立集时，反复等待直到有利子集出现再承诺，其盈余在任意固定 γ∈(0,1) 下仍严格为正。从而**移除了原证明中"γ 需充分接近 1"的要求**。

### 2.3 近最优规划（Theorem 2，RPTAS）
- **两阶段算法**：
  - **离线阶段（Algorithm 1）**：从 Q 采样 N 个转移表 `Θ_1,...,Θ_N`，构造有限字典状态空间 `C_N = S × [N]^ℓ`，在其上运行 K 步值迭代：
    `v_{k+1}(s,i_0,...,i_{ℓ-1}) = max_a { r(s,a) + (γ/N) Σ_j v_k(Θ_{i_0}(s,a), i_1,...,i_{ℓ-1}, j) }`。
  - **在线阶段（Algorithm 2）**：观测到任意窗口 `c=(θ_0,...,θ_{ℓ-1})`（不一定在字典中），从 `V_K` 出发**逆向递推**，将观测到的表 `θ_{ℓ-1},...,θ_0` 逐一"精确插入"，仅对超出观测视野的新表用字典做平均，得到分数 `Q̃_{V_K}(s,c,a)` 并取贪心。
- **关键洞察**：同一批采样表既用于定义经验分布 `Q̂_N`，又用于构造有限状态空间 `C_N`；有限 MDP 与经验增广 MDP 在字典窗口上有相同的 Bellman 方程，因此 `V*_N(s,i) = V̂*(s,Θ_i)`。
- **误差分解**：采样误差（Hoeffding + 对全部窗口一致并集界，`‖V̂*-V*_ℓ‖_∞ ≤ γη/(1-γ)`）+ 值迭代截断误差（`γ^K V_max`）+ 在线递推的稳定性（每步 γ-Lipschitz，共 ℓ 步）。
- **参数选择**：`N = ⌈(8/(ε²(1-γ)⁴))(log(2/δ) + (1+(ℓ-1)nm)log n)⌉`，`K = ⌈(1/(1-γ))log(4/(ε(1-γ)))⌉`；对固定 ℓ，时间与内存关于 `n, m, ε^{-1}, log(1/δ), (1-γ)^{-1}` 多项式。

### 2.4 遗憾最小化（Theorem 3，DLA-UCB）
- **设定**：转移核 P 与均值奖励 r 均未知，性能度量为累积 Bellman 间隙 `Reg_ℓ(T)`。
- **算法（Algorithm 3–4）**：从历史转移表估计各边际 `P̂_N(·|s,a)` 并取乘积得 `Q̂_N`；采样 `M_N = ⌈N/(1-γ)³⌉` 个字典表；在 `S × [M_N]^ℓ` 上做**乐观值迭代**，使用方差自适应置信界：
  `U_N(y) = min{V_max, ȳ + 8V_max α_N ρ_N + max{7α_N s(y), 49 V_max α_N²}}`。
  其中 `α_N` 为 Bernstein 型转移奖励项、`ρ_N` 为 Hellinger 型一致误差项。在线仍用同一逆向递推。规划器仅在样本数或奖励计数翻倍时重算。
- **误差两步分解**：`Q → Q̂_N`（统计估计误差）→ `{Θ_1,...,Θ_{M_N}}`（蒙特卡洛误差）。
- **技术工具**：乘积估计量的 Bernstein 界（通过随机置换重匹配构造 i.i.d. 副本）、Hellinger/方法类型（method of types）一致界、乐观不动点、可预测到实现的比较引理、折扣总方差引理（Freedman 不等式）。
- **遗憾结果**：`Reg_ℓ(T) = Õ(R_max√(nmT/(1-γ)) + R_max n²m/(1-γ)²)`，主项与经典表格型折扣 RL 最优依赖一致。

### 2.5 扩展：噪声前瞻（Appendix C，Theorem 4–5）
- 观测的是被局部噪声信道 `I(·|s,a,s')` 污染的噪声表 `Θ̃_t`，真实后继需通过后验 `P̃(s'|s,a,z)` 推断。
