## 摘要
离线到在线强化学习降低了真实世界机器人学习的交互成本，但持续存在价值估计不稳定的问题。现有方法通过悲观正则化、下界校准和架构归一化来解决这一问题，但一个被忽视的不稳定来源在于熵公式：标准的对数熵项可能变为负值，从而使策略更新不稳定。我们提出 SCQ（Sigmoid 有界保守 Q 学习），它将这一项替换为严格保持为正的 Sigmoid 有界形式。SCQ 保留了保守 Q 正则化和基于回报的下界校准，在不牺牲探索的情况下稳定策略优化。我们在单示范和标准数据集设置下的 D4RL (Minari) 基准上评估 SCQ，并在仿真和真实世界视觉任务上进行评估。SCQ 在基于状态和视觉基准上达到或超过基线性能，同时表现出更稳定的训练动态，并迁移到四个真实机器人平台，包括操作、轮式、四足和人形系统。一种去除负对数概率贡献的直接裁剪干预，连同梯度匹配的正分数对照，表明正值性而非仅特定分数形状驱动了大部分改进。项目网站：https://scq-rl.github.io。

## Abstract
Offline-to-online reinforcement learning reduces interaction cost for real-world robot learning but suffers from persistent value estimation instability. Existing methods address this through pessimistic regularization, lower-bound calibration, and architectural normalization, but an overlooked source of instability lies in the entropy formulation: the standard log-entropy term can become negative, destabilizing policy updates. We introduce SCQ (Sigmoid-Bounded Conservative Q-Learning), which replaces this term with a sigmoid-bounded formulation that stays strictly positive. SCQ retains conservative Q regularization and return-based lower-bound calibration, stabilizing policy optimization without sacrificing exploration. We evaluate SCQ on D4RL (Minari) benchmarks under both single-demonstration and standard dataset settings, as well as on simulation and real-world visual tasks. SCQ matches or exceeds baseline performance while exhibiting more stable training dynamics across state-based and visual benchmarks, and transfers to four real-robot platforms including manipulation, wheeled, quadruped, and humanoid systems. A direct clipping intervention that removes negative log-probability contributions, together with gradient-matched positive-score controls, indicates that positivity rather than a particular score shape alone drives much of the improvement. Project website: https://scq-rl.github.io.

## 1. 核心问题与整体含义

- **研究背景**：离线到在线强化学习（offline-to-online RL）先用演示数据预热策略，再通过在线交互改进，可显著降低真实机器人学习的交互成本。但该范式长期受**价值估计不稳定**困扰，在一次性演示（one-shot）、有限回放等低数据场景下尤为严重。
- **已有手段及其局限**：现有方法主要依赖三类稳定化技术——保守 Q 正则（CQL）、基于回报的下界校准（Cal-QL）、critic 端 LayerNorm（RLPD），但策略优化仍会出现振荡甚至学习失败。
- **本文识别出的被忽视因素**：在最大熵 actor-critic（SAC 类）中，对 tanh-squashed Gaussian 策略而言，**标准的逐样本对数熵项（log-probability entropy）可能取负值**。该负项被加到 Q 值上后，会在采样动作附近**局部压低熵增强目标**，改变策略均值更新的幅度与方向。
- **失稳反馈回路**：策略均值移动 → critic 被查询的动作改变 → 价值估计变化 → 影响下一次策略更新。在有限回放下，该反馈会被放大，造成策略均值振荡与价值估计发散。
- **整体含义**：论文主张熵公式本身是一个此前未被处理的失稳来源，并通过将其改造为**严格为正、有界**的形式来稳定 Q 学习求解器，使低数据、无预训练策略骨干、跨形态部署成为可能。

## 2. 方法论

### 2.1 核心思想：Sigmoid 有界熵（SigEnt）

- 设逐维 surprisal 为 ℓᵢ = −log π_θ,i(aᵢ|s)，用 logistic sigmoid 定义有界熵贡献：
  - hᵢ(ℓᵢ) = h_max · sigmoid((ℓᵢ − m)/t)
  - H_sig(s, a; θ) = Σᵢ hᵢ(ℓᵢ)，**取值严格落在 (0, d_a·h_max)**
- 关键性质：熵贡献**永不变号**（始终为正），且有上界，从而不会反向扭曲有效 Q 景观、不会无界放大。
- 设计准则：把实际策略散布区间放在 sigmoid 的**响应区**（而非饱和尾部）。

### 2.2 Actor 与温度学习

- Actor 目标：L_π = E[ −min_i Q_i(s,a) − α·H_sig(s,a;θ) ]，其中 a ~ π_θ。
- 温度 α 自动调节，使期望有界熵匹配目标：E[H_sig] = H_target。
- 采用共享的目标预 squash 标准差 σ_tar = 0.1，令 H_target = d_a·h(ℓ̄(0.1)) ≈ 0.25743·d_a；该目标只用于实例化自动温度调节，不改变 SigEnt 形状。

### 2.3 Critic 学习

- 熵增强 Bellman 目标：y = r + (1 − d_term)·γ·(min_i Q̄_i(s′,a′) + α·H_sig(s′,a′;θ))。
- 基础 TD 损失 L_TD 为平方误差；在此基础上加入**简化 CQL 风格保守正则** L_CQL（沿用 Cal-QL 形式）：对来自 s 与 s′ 的策略采样动作，先用 Monte-Carlo 回报做下界校准，再以 log-sum-exp 形式对 buffer 动作值施加惩罚。
- 最终 critic 目标：L_Qᵢ = L_TD⁽ⁱ⁾ + λ_cql·L_CQL⁽ⁱ⁾。
- **Critic-only LayerNorm**：仅在 critic 网络中施加 LayerNorm，actor 结构不变，避免引入额外策略正则。

### 2.4 理论性质

- **定理 1（理想化 SigEnt Backup 的收缩性）**：在固定策略、精确期望、忽略目标网络滞后的理想设定下，熵项与 Q 无关故在比较备份时抵消，有限集成取 min 为非扩张算子，因此该算子为 γ-收缩，存在唯一不动点，精确 Q 迭代收敛。
- **定理 2（αH 平衡等变性）**：若 h_max → h_max/c、H_target → H_target/c，同时 α → cα*，则 α′H′_sig = α*H_sig 保持不变，(Q*, θ*, α′) 仍是重缩放系统的稳定平衡点。说明 **h_max 不是独立的平衡尺度参数**。
- 由此采用**规范化的共享动作坐标形状参数化**：固定 h_max = 1，逐维形状 (m, t) = (−0.3, 0.55) 全局固定，不随任务、奖励、数据、动作维度或物理单位变化。
- 在该形状下，σ ∈ [0.105, 0.304] 可保留至少 80% 的最大分数导数（高敏感区间），共享的 σ_tar = 0.1 落于其中。
