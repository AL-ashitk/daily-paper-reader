## 摘要
我们研究强化学习中最优价值的离线推断。我们推导出两个新的干扰参数，它们是自诱导贝尔曼方程的不动点，其中我们将最大贝尔曼算子用其 softmax 对应形式来近似。我们通过 Neyman 正交性提出一个去偏估计量，并在时域发散的情形下建立其渐近正态性，即使行为策略随时间变化，只要这些干扰参数具有许多机器学习方法可达到的统计速率。我们为这些干扰参数提供了一个具体的估计步骤，并表明它们能够带来有效的推断。合成实验验证了我们推断方法的数值性能，并将其应用于现实决策问题，包括共享单车再平衡和 AI 智能体工具使用。

## Abstract
We study offline inference for the optimal value in reinforcement learning. Two new nuisances are derived as fixed points of a self-induced Bellman equation, in which we approximate the maximum Bellman operator by its softmax correspondence. We propose a debiased estimator through the Neyman orthogonality and establish its asymptotic normality under diverging horizons even when the behavior policy changes with time, as long as the nuisances have the statistical rates that can be achieved by many machine learning methods. We provide a concrete estimating procedure for these nuisances and show they can lead to valid inference. Synthetic experiments validate the numerical performance of our inference method, and we implement it in real-life decision-making problems, including bike repositioning and AI agentic tool use.

- **核心问题**：给定由**非最优**行为策略生成的观测轨迹（且行为策略可随时间变化、观测时域可发散），能否推断出最优平均奖励 J\* 并给出渐近有效的置信区间？

## 2. 方法论

### 2.1 核心思想：自诱导 Bellman 方程

- **事后 softmax 路线的问题**：先由 Bellman 最优方程估计 Q\*，再对其施加 softmax 得到策略并做固定策略 OPE。该路线中策略生成与延续值评估是分离的，误差分解会多出一项"上游策略学习误差"，且 Q\* 的递推由非光滑 max 算子决定，在非唯一最优时非正则。
- **自诱导构造**：直接对 Bellman 递推本身做 softmax 平滑，要求"生成策略"与"评估该策略延续值"由同一个 Q 自洽确定：
  - softmax 策略：π_{β,Q}(a|s) = exp(βQ(s,a)) / Σ_b exp(βQ(s,b))
  - 平滑值映射：V_β(Q)(s) = Σ_a π_{β,Q}(a|s) Q(s,a)
  - 自诱导平均奖励 Bellman 方程：**J_β + Q_β(s,a) = R\*(s,a) + E[ V_β(Q_β)(S') | S=s, A=a ]**
- **自洽性质**：Q_β 同时诱导策略 π_β 并评估其延续值；J_β 恰为 π_β 的普通长期平均奖励。因此总体上消除了"策略生成—策略评估"的割裂。

### 2.2 理论性质

- **存在性**：用 Brouwer 不动点定理，在不可约性假设下对任意 β>0 存在锚定解 (Q_β, J_β) ∈ Q × R。
- **唯一性**：在 Assumption 3.4（对所有"允许的符号聚合算子" D，−j1 − q + P Dq = 0, q∈Q 蕴含 q=0, j=0）下唯一。Dobrushin 系数条件 C_A ρ(P) < 1（C_A = 1+2log|A|）是其可解释的充分条件。
- **平滑偏差**：0 ≤ J\* − J_β ≤ C e^{−βΓ}，其中 Γ 为最小正最优性间隙；若 Γ=∞（处处并列）则 J_β = J\* 精确成立。同时 Q_β→Q\*、π_β→π_unif（并列最优动作上的均匀策略）、D_β→D_{π_unif}。

### 2.3 正交分数与去偏估计

- **导数权重**：ω_{β,Q}(a|s) = π_{β,Q}(a|s)[1 + β(Q(s,a) − V_β(Q)(s))]，满足行和为 1、符号 ℓ₁ 上界 1+2log|A|。由此定义聚合算子 (D_β q)(s) = Σ_a ω_{β,Q_β}(a|s) q(s,a)。
- **伴随权重 λ_β**：满足归一化 E_{P̄}[λ_β(S,A)] = 1，以及对所有 q∈Q 的伴随矩条件 E_{P̄}[λ_β(S,A)(q(S,A) − (D_β q)(S'))] = 0；存在唯一。
- **正交分数**：φ_β(Z; J,Q,λ) = J + λ(S,A)( R − J + V_β(Q)(S') − Q(S,A) )。
- **Neyman 正交性**：总体矩 E_{P̄}[φ_β] 在真值 (J_β, Q_β, λ_β) 处对 J、Q、λ 三个方向的一阶方向导数均为零；λ_β 同时抵消 Q_β 扰动与诱导策略扰动的一阶效应。
- **交叉拟合估计量**：将 N 条轨迹分成 K 折，bJ_β = (1/N) Σ_k Σ_{i∈I_k} (1/H) Σ_t φ_β(Z_{i,t}; bJ_{−k}, bQ_{−k}, bλ_{−k})。

### 2.4 渐近正态性与方差

- **两种机制**：
  - (i) H 固定、N→∞，要求干扰余项 max_k b_k = o_p(N^{−1/2})；
  - (ii) H→∞，要求 max_k b_k = o_p((NH)^{−1/2}) 且行为过程强混合系数可和（Assumption 4.9）。
- **结论**：√(NH)(bJ_β − J_β)/σ →_d N(0,1)；若 √(NH) e^{−βΓ} → 0，则对 J\* 同样成立。
- **方差**：σ² = E_{P̄}[λ_β(S,A)² Var(R + V_β(Q_β)(S') | S,A)]，由 Bellman 方程使分数增量成为鞅差序列，跨时间协方差为零，从而 H 步信息可累积到 √(NH) 速率。
- **可行方差估计**：bσ² = (1/(NH)) Σ_k Σ_{i∈I_k} Σ_t bξ²_{i,t}，两种机制下均相合，可构造 Wald 置信区间。

### 2.5 干扰参数的具体估计

- **Bellman 对 (Q_β, J_β)**：在一步 i.i.d. 过渡样本上，用带正则的 minimax 估计，准则为对检验函数类 G 取上确界：sup_{g∈G} { 2P_n[g(R − J + V_β(Q)(S') − Q(S,A))] − ρ P_n[g(S,A)²] }。有限样本速率 ∥bQ − Q_β∥ + |bJ − J_β| ≲ √(|S||A| log n / n)。
- **伴随权重 λ_β**：构造经验伴随矩方程准则，用稳定化范数 ∥q∥_τ² = P_n[q²] + (n|S||A|)^{−1} Σ_{s,a} q(s,a)²，并以 bQ 替换未知 Q_β 得到可行准则。速率 ∥bλ_β − λ_β∥ = O_P(√(log n/n + β√(log n/n)))。
- **可行 β 范围**：log n ≪ β ≪ √n / (log n)^{3/2}，同时保证平滑偏差为 o(n^{−1/2}) 且干扰速率满足正交推断要求。
