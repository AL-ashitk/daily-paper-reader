## 摘要
稀疏的结果反馈限制了机器人能够从复杂操作的失败尝试中学到什么。失败的多阶段手术操作尝试可能包含值得复用的抓取、提举或转移动作。在稀疏奖励强化学习中，终端奖励将此类尝试归并为相同结果，而标量视觉语言模型（VLM）评分既不能揭示哪些进展应获得信用，也不能揭示其何时发生。我们提出阶段与首次到达反馈：对每个记录回合进行一次VLM查询，识别视觉验证的最远任务阶段以及首次到达该阶段的时间，从而使学习器能够复用部分行为并进行信用定位。我们在SurgPhaseBench中实现该反馈，这是一个涵盖刚性和可变形任务的阶段结构化测试套件，并在仿真和硬件上对其进行评估。在五个仿真任务中，我们的方法达到75.2%的平均成功率，而基于对比语言-图像预训练（CLIP）且使用相同视觉输入的奖励为52.1%；当仅改变反馈表示时，这一优势依然存在。在硬件上，同一记录支持自主方块拾取和滑移恢复。总之，这些结果表明，轨迹级视觉监督能够保留部分进展，同时提供稀疏奖励控制所需的时序信用。

## Abstract
Sparse outcome feedback limits what robots can learn from unsuccessful attempts at complex manipulation. Failed multi-stage surgical attempts can contain grasps, lifts, or transfers worth reusing. In sparse-reward reinforcement learning, terminal rewards collapse such attempts to the same outcome, while scalar vision-language model (VLM) ratings reveal neither what progress merits credit nor when it occurred. We introduce phase-and-first-arrival feedback: one VLM query per recorded episode identifies the furthest visually verified task phase and when that phase is first reached, allowing the learner to reuse partial behavior and localize credit. We instantiate it in SurgPhaseBench, a phase-structured suite spanning rigid and deformable tasks, and evaluate it in simulation and hardware. Across five simulated tasks, our method reaches 75.2% mean success, compared with 52.1% for a reward based on Contrastive Language-Image Pre-training (CLIP) using the same visual input; the advantage persists when only the feedback representation changes. On hardware, the same record supports autonomous block picking and slip recovery. Together, these results show that trajectory-level visual supervision can preserve partial progress while providing the temporal credit needed for sparse-reward control.

## 1. 核心问题与研究背景

- **稀疏奖励困境**：在多阶段手术操作任务中，终端二值成功奖励把所有失败回合压成同一回报，使得"抓取并提举后掉落"与"从未接触目标"在信用分配上毫无差别，浪费了失败回合中可复用的部分行为（grasp/lift/transfer）。
- **现有方案的两难**：
  - **密集塑形奖励**：虽能恢复部分信号，但需按任务手工编写，且依赖硬件不暴露的特权仿真器状态，难以迁移到新术式或真实机械臂。
  - **标量 VLM 评分**：一次查询即可给整段轨迹打分，经济但分辨率低——只报告"有多好"，不指出"哪一步获得了信用、何时发生"。
  - **逐帧 VLM 评分**：能定位时间，但查询代价随帧数线性增长，与 RL 对"信用绑定到具体转移"的需求相反。
- **核心研究问题**：能否用**每回合一次查询**，同时保留轨迹级反馈的经济性，又能在时间上定位可复用行为？
- **整体含义**：论文提出"阶段与首次到达（Phase-and-First-Arrival）"反馈，将一次 VLM 查询转化为结构化进度与时序记录，为稀疏奖励控制提供部分进展复用与时间信用分配，在仿真与真实硬件上验证有效。

## 2. 方法论

### 2.1 核心思想
- 对每个**支撑回合（support episode）** 只查询一次冻结的 VLM，读取带时间戳的"故事板"，返回三元组：
  - `ˆqi`：视觉验证的**最远任务阶段**（如 approach/grasp/lift/at-goal/success）；
  - `ˆti`：该阶段**首次到达的时间区间**（bracket）；
  - `ci`：自报告置信度，用于门控。
- 关键洞察：**阶段识别可复用的部分进展，首次到达把信用定位到具体转移邻域**，从而在不牺牲查询经济性的前提下获得时间分辨率。

### 2.2 关键技术细节
- **任务契约**：每个任务 T 由作者提供描述 `dT`、有序阶段词表 `QT = (q0 ≺ … ≺ qK)`、以及单调映射 `ρT: QT → {0,…,K}`（`ρT(q0)=0`）。不同任务的标签映射到共享进度秩（none, approach, grasp, lift, at-goal, success），使同一观察器与编译器跨任务通用。
- **故事板适配器 `AT`**：将回合视频转成 7 个面板（6 个等时间网格的时序合成图 + 1 个首尾运动差分图），每帧含全视图、任务指定的裁剪区域与时间戳标签。
- **门控与编译**：
  - 接受条件：`ci ≥ cmin`、`ˆki > 0`、且到达区间有效（`0 ≤ ˆti,ℓ ≤ ˆti,u < Ti`）。
  - 中点 `¯ti = (ˆti,ℓ + ˆti,u)/2`，窗口 `Wi = {t : |t − ¯ti| ≤ h}`（h ≥ 1/2 保证非空）。
  - **辅助奖励（式 1）**：`˜ri,t = ri,t + (gˆki / |Wi|) · 1[t ∈ Wi]`，其中 `g` 为共享总信用调度，保证窗口内信用总和恰为 `gˆki`。
  - **高斯到达权重（式 2）**：`ωi,t = exp(−(t − ¯ti)² / (2σ²))`，用于采样与行为克隆。
  - **固定采样分布（式 3）**：`pΦ(i,t) ∝ 1 + ηr(˜ri,t − ri,t) + ηaωi,t`，学习期间冻结。
- **在线学习（SAC + 冻结阶段库）**：
  - 混合小批量：`pmix = m·pΦ + (1−m)·pon`（m 为 bank 比例）。
  - bank 转移用 `˜r` 做 critic 目标，在线转移仍用环境 `r`。
  - **Q 过滤**：当 bank 动作 `at` 在 `ot` 处的 `Qmin,ψ` 不低于评估动作 `aeval_θ(ot)` 时 `χi,t = 1`，否则为 0。
  - **加权 BC 损失（式 4）**：`LBC = Σχi,t ωi,t ℓi,t / Σχi,t ωi,t`。
  - **Actor 损失（式 5）**：`Lactor = Lactor_SAC + λBC · LBC`。
  - 训练前先以 `χ≡1` 进行加权 BC 预热；采集与评估始终只用稀疏环境奖励，部署时不再查询 VLM。

### 2.3 算法流程（Algorithm 1）
1. 对每个支撑回合做一次 VLM 查询，得到 `(ˆqi, ˆti, ci)`，映射为秩 `ˆki`；
2. 通过门控后按式 (1)-(3) 编译出 `˜r`、`ω`、`pΦ`，插入冻结 bank `BΦ`；
3. 冻结 bank，用加权 BC 预热策略；
4. 在线循环：用 `πθ` 采集入 `Bon` → 按比例 m 混合采样 → 用 `˜r` 更新 SAC critic → 按式 (5) 更新 actor。

## 3. 实验设计

### 3.1 Benchmark：SurgPhaseBench
- 基于 **ManiSkill3** 构建的 **12 个阶段结构化环境**，覆盖刚性与基于 Warp 的可变形交互。
- 任务谱系：reach、grasp-and-lift、transfer、insertion、threading、reorientation、stacking、deformable pulling。
- **5 个策略学习任务**（完整观察器–编译器–学习器闭环）：BlockPick、NeedlePick、PegTransfer、ShuntInsert、GauzePull；其余 7 个（NeedleReach、RingRemove、RingStack、PSMReach、ThreadHoop、MatchBoard 等）用于验证执行与语义广度。
- 五个任务 horizon 分别为 75/75/90/90/220 步；BlockPick、NeedlePick、NeedleReach、ShuntInsert 共用近距抓取辅助，GauzePull 使用 Warp 软体附着模型。

### 3.2 对比方法
- **MultiTile-CLIP**：CLIP-RM 应用于 7 图块视图（同视觉输入的主对照）。
- **BT-Pref**：成对偏好比较。
- **Likert-RM**：标量评分。
- **无反馈 SAC**、**单视图 CLIP-RM**、**Oracle-Support**（同池但用真值阶段标签，作为性能上限）。
