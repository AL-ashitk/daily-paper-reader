## 摘要
在保护深度强化学习（DRL）策略免受输入扰动影响方面已取得显著进展。开发鲁棒 DRL 涉及三个主要阶段：算法设计、实现和评估。在这项工作中，我们识别并解决了每个阶段的一个关键局限。首先，我们引入了对抗重要性采样（Advis），一种对来自标准训练的轨迹进行重要性采样，以估计并优化可验证最坏情况回报的方法。Advis 满足三个理想标准，而先前工作未能同时实现这些标准：它不需要额外的环境交互，不需要辅助网络，并且能够捕捉长期鲁棒性。其次，我们引入了 advrl，一个模块化的 PyTorch 库，为现有鲁棒性方法和对抗攻击提供简洁的单文件实现，便于快速原型设计，并支持可复现且可追溯的评估。第三，我们重新审视了在学习型对抗者下的评估，并表明最优对抗超参数不会在不同智能体之间迁移，这在使用有限攻击者配置时可能导致对鲁棒性的高估。因此，我们使用比先前工作多 6-14 倍的配置，针对大量且多样的攻击者集合评估策略。最后，我们在连续控制环境中评估了我们的方法，展示了其相对于现有基线的有效性。代码可在以下网址获取：https://github.com/AmineAndam04/advrl

## Abstract
Significant progress has been made in safeguarding deep reinforcement learning (DRL) policies against input perturbations. Developing robust DRL involves three main stages: algorithm design, implementation, and evaluation. In this work, we identify and address a key limitation at each stage. First, we introduce Adversarial Importance Sampling (Advis), a method that uses importance sampling over trajectories from standard training to estimate and optimize verifiable worst-case returns. Advis satisfies three desirable criteria not jointly achieved by prior work: it requires no additional environment interactions, no auxiliary networks, and captures long-term robustness. Second, we introduce advrl, a modular PyTorch library that provides clean, single-file implementations of existing robustness methods and adversarial attacks, facilitating rapid prototyping and enabling reproducible and traceable evaluations. Third, we revisit evaluation under learned adversaries and show that optimal adversarial hyperparameters do not transfer across agents, which can lead to an overestimation of robustness when using a limited set of attacker configurations. Accordingly, we evaluate policies against a large and diverse set of attackers, using 6-14x more configurations than prior work. Finally, we evaluate our approach on continuous control environments, demonstrating its effectiveness relative to existing baselines. The code is available at: https://github.com/AmineAndam04/advrl

## 2. 方法论：Adversarial Importance Sampling (Advis)

### 核心思想
- 结合**神经网络凸松弛**与**重要性采样（IS）**：先用凸松弛计算可证明的最坏情况策略分布 $\pi^{wc}$，再**复用标准 PPO 训练中已采集的轨迹**，通过重要性采样估计 $\pi^{wc}$ 的折扣回报，并将其作为鲁棒正则项优化。
- 优势：无需额外环境交互、无需辅助网络、天然捕捉长期（轨迹级）鲁棒性。

### 关键技术细节
- **构造最坏策略 $\pi^{wc}$**：对高斯策略 $\pi_\theta(\cdot|s)=\mathcal{N}(\mu_\theta(s),\Sigma_\theta)$，在扰动集 $B_\epsilon(s)$ 下用凸松弛工具（auto_LiRPA）求均值上下界 $[\underline{\mu}_\theta, \overline{\mu}_\theta]$，并按优势函数符号取闭式解：$A_t>0$ 时取使动作概率最小的 $\mu^+_\theta$，否则取 $\mu^-_\theta$（Eq. 7）。
- **IS 估计**：用重要性权重 $\rho^{advis}_t(\tau)=\prod_{k=0}^{t}\frac{\pi^{wc}(a_k|s_k)}{\pi(a_k|s_k)}$ 估计 $\hat{J}(\pi^{wc})$，等价于对最坏情况策略做离策略评估。
- **三种鲁棒目标（归纳偏置不同）**：
  - 最大化最坏情况性能：$\mathcal{L}^{advis\text{-}wc}_{robust}=-\hat{J}(\pi^{wc})$（Eq. 13）
  - 最小化干净/最坏回报 MSE：$(J(\tau)-\hat{J}(\pi^{wc}))^2$（Eq. 14）
  - 仅惩罚性能下降：$\max(0, J(\tau)-\hat{J}(\pi^{wc}))$（Eq. 15）
- **缓解高方差与分布失配**：
  - **$\epsilon$-scheduling**：训练中逐步增大攻击预算，限制早期 $\pi$ 与 $\pi^{wc}$ 的偏离。
  - **低方差 IS 估计器**：PDIS（无偏、低方差）、WIS、WPDIS（有偏但一致、方差显著更低）。
  - **轨迹窗口**：在采样的轨迹窗口而非完整轨迹上计算估计，缓解“诅咒的时域”（Curse of Horizon）。
  - **数值稳定**：PDIS 权重截断、WIS 采用 log-sum-exp 技巧。
- **轨迹级正则（Lemma 1）**：选取 Rényi 散度作为轨迹分布差异度量，可得到 OIS 估计器方差的上界 $\mathrm{Var}[\hat{J}_{IS}]\le \frac{\|R\|_\infty^2}{N}d_2(p(\cdot|\pi^{wc}),p(\cdot|\pi))$，且指数化 2-Rényi 散度可用权重平方归一化形式（Eq. 17）高效估计，最小化它可同时提升鲁棒性与稳定性。

### 配套工具库 advrl
- 模块化 PyTorch 库，单文件实现 PPO、SA-Reg、Radial、SA-ATLA、PA-ATLA、WocaR-RL、Advis 及 Random/Critic/MAD/RS/SA-RL/PA-AD 攻击。
- 提供标准化配置（ml_collections）、受控随机种子、可移植 checkpoint、CPU 多核并行评估、完整日志（`seeds.json`、`metadata.json`、`metrics.json`）以支持可复现与可追溯。

## 3. 实验设计

- **场景/数据集**：MuJoCo 连续控制三环境——**HalfCheetah-v5、Hopper-v5、Walker2d-v5**（$\epsilon$ 分别为 0.15、0.075、0.05），基于 PPO，统一网络结构（2 层 MLP，每层 64 神经元），统一 $\epsilon$-scheduler（75% 训练步数内线性增至满预算）。
- **Benchmark / 对比方法**：SA-Reg、Radial、SA-ATLA、PA-ATLA、WocaR-RL（ACoE 因 200 万步未收敛被排除）。
- **攻击集合**：Random（Uniform/Gaussian/Fixed）、Critic、MAD、RS、SA-RL、PA-AD。学习型攻击使用网格搜索超参。
- **评估规模**：每个智能体对 **1296 个 PA-AD 攻击者**（432 配置 × 3 种子）、600 个 SA-RL、432 个 RS——比先前工作的 30–200 个多 **6–14 倍**；每个攻击评估 1000 回合（20 种子 × 50 回合），3 个训练随机种子。
- **指标**：最小回报、**CVaR$_\alpha$**（最差 $\alpha$% 攻击者的平均回报）、IQM 等尾敏感指标；并指出 mean/median 会误导（Fig. 1 中 Agent 5 无灾难性失败却未被 mean/median 排第一）。

## 6. 主要结论与发现

- **Advis 在鲁棒性上一致最优**：Table 2 的“Best Attack”最坏情况回报列中，Advis 在三环境均取得最强或接近最强的鲁棒表现，且方差相对较小。
- **CVaR 曲线**：在 HalfCheetah 与 Hopper 上，Advis 在整个 $\alpha\in[0.01,0.1]$ 范围内占优；Walker2d 呈分化——$\alpha\le 0.02$ 的极端尾部事件上 Advis 优于 SA-Reg，$\alpha>0.02$ 时相反，说明**算法排名随风险偏好而变**。
- **IS 估计器**：加权变体（WIS、WPDIS）通常优于 PDIS，尤其在低 $\alpha$；WPDIS 方差显著更低。
- **对抗损失**：无单一损失在所有环境一致最优，最佳损失依赖环境，需调参。
- **评估方法学**：最优对抗超参不跨防御迁移，少量攻击者配置会高估鲁棒性；应使用大规模、多样攻击者集合与尾敏感指标（最小回报、CVaR）。
- **实现层面**：揭示并修正了既有代码库中的多个问题（如 SA-Reg SGLD 的 bug、Radial 伪代码与实现不符、WocaR-RL 缺失组件、legacy MuJoCo 依赖等）。

## 7. 优点

- **方法设计优雅**：用凸松弛得到可证明最坏策略 + 重要性采样复用现有轨迹，**同时满足“无额外样本、无辅助网络、长期鲁棒”**三条标准，填补了 Table 1 的空白。
- **理论支撑**：Lemma 1 给出 IS 估计器方差与 2-Rényi 散度的上界关系，并据此设计可估计的轨迹级正则项，兼顾鲁棒与稳定。
- **工程贡献扎实**：advrl 提供模块化、单文件、可复现、可追溯、可移植的库，解决社区代码库混乱问题，并支持大规模并行评估。
- **评估方法学贡献**：量化揭示对抗超参不迁移现象，并采用 6–14 倍更多攻击者配置与 CVaR 等尾敏感指标，提升了鲁棒性评估的可靠性。
- **诚实与透明**：明确指出 ACoE 未收敛而排除、Walker2d 的分化现象、Hopper 上轨迹正则失效、以及各方法超参搜索空间，减少夸大结论的风险。

## 8. 不足与局限

- **应用范围有限**：仅聚焦连续控制的策略优化（PPO/MuJoCo 三环境），未验证离散动作、其他 RL 范式（如 off-policy、model-based）或高维视觉输入。
- **实验规模仍偏小**：环境数仅 3 个，训练种子仅 3 个；对统计显著性与跨任务泛化性的支撑有限。
- **对比公平性存疑**：Advis 使用 5 个环境、基线用 2 个，学习率也不同，虽给出理由，但严格意义上并非完全对等。
- **干净性能代价**：Advis 的自然回报在部分环境低于部分基线（如 Hopper 上低于 SA-Reg、SA-ATLA），存在鲁棒性与干净性能的权衡，论文未深入讨论。
- **评估成本高**：每个智能体上千攻击者、每组 1000 回合的评估代价大，可能限制更广泛采用。
- **算力信息缺失**：未报告 GPU 型号/数量/总训练时长，可复现成本不透明。
- **依赖外部工具**：凸松弛依赖 auto_LiRPA，估计质量受松弛紧致度影响；轨迹级正则的理论收益在 Hopper 上未体现。
- **部分结论依赖单一实现**：如“网格搜索优于随机搜索”的结论仅在 PA-ATLA + RS 攻击的组合上验证，泛化性有限。
