## 摘要
跨多个领域的强化学习（RL）可以拓宽大语言模型（LLMs）的推理能力，但联合训练往往会降低单个领域的性能，并可能使优化不稳定。现有工作通常从单步视角出发，利用一阶梯度对齐或基于曲率的代理指标来诊断此类干扰。我们表明，这种视角可能遗漏一种关键的序列干扰形式：同一位置的领域梯度可能仍近乎正交，即便连续的实际更新在输出空间中部分地相互逆转。我们进一步表明，连续 token 的对数概率足迹能够直接从相邻检查点恢复这种交互，将其视为输出空间中的局部二阶交互，而无需显式重构同一步的曲率。基于这一洞见，我们提出 OSOL，其在每次迭代中指定一个聚焦领域，使用前一个检查点足迹对 token 级反弹风险进行排序，并在标准 GRPO 更新中应用按漂移排序、自适应缩放的校正。我们的分析表明，该校正抑制了目标跨步输出回溯分量。对照研究进一步表明，与同点梯度诊断相比，跨步回溯与后续任务损害的相关性更强；同时，前序足迹对未来反弹风险的排序比基于 Hessian 的代理指标更准确。在 Qwen3-30B-A3B 上，OSOL 达到 0.4822 的领域宏平均，相较最强对比基线提升 5.7%，且无需显式高阶微分。

## Abstract
Reinforcement learning (RL) across multiple domains can broaden the reasoning capabilities of large language models (LLMs), yet joint training often degrades individual-domain performance and can destabilize optimization. Existing work typically diagnoses such interference from a single-step view using first-order gradient alignment or curvature-based proxies. We show that this view can miss a critical form of sequential interference: same-point domain gradients may remain nearly orthogonal even when consecutive realized updates partially reverse one another in output space. We further show that consecutive token log-probability footprints recover this interaction directly from adjacent checkpoints as a local second-order interaction in output space, without explicitly reconstructing same-step curvature. Building on this insight, we propose OSOL, which designates a focus domain at each iteration, uses the preceding checkpoint footprint to rank token-level rebound risk, and applies a drift-ranked, adaptively scaled correction within the standard GRPO update. Our analysis shows that this correction suppresses the targeted cross-step output backtracking component. Controlled studies further show that cross-step backtracking is more strongly associated with subsequent task damage than same-point gradient diagnostics, while the preceding footprint ranks future rebound risk more accurately than Hessian-based proxies. On Qwen3-30B-A3B, OSOL reaches a domain-macro average of 0.4822, improving by 5.7% over the strongest compared baseline, without explicit higher-order differentiation.

## 2. 方法论（OSOL）

### 2.1 核心思想

- **跨步输出几何**：以 token 对数概率足迹（log-probability footprint）刻画一次参数更新在固定已实现响应 token 坐标上的对数概率变化。
- **可观测性**：相邻两个 checkpoint 的 token 足迹内积，能够以局部二阶交互的形式恢复两次连续更新的混合交互，而无需显式构造 Fisher 矩阵或 Hessian。
- **一步一导（One Step, One Lead）**：每次迭代指定**唯一焦点领域**，仅对其合格响应 token 施加基于历史漂移的修正；其余领域以较小权重保留在同一更新中，从而"优先一个领域但不丢弃其他领域"。

### 2.2 关键技术细节与公式（文字说明）

- **输出 KL 与 Fisher**：
  - 定义焦点域 token 上下文上的输出 KL 散度 D_k(δ)。
  - **引理1**：该 KL 在锚点处的一阶导为 0、二阶导恰为输出 Fisher F̄_k，即 D_k(δ) = ½ δᵀF̄_kδ + O(‖δ‖³)。强调这是输出 KL 的精确局部 Hessian（自然梯度/信赖域所用量度），而非把完整目标 Hessian 等同于 Fisher。
- **检查点 token–Fisher 对偶（定理1）**：
  - 设前序更新 δ_{k−1} = θ_k − θ_{k−1}，当前基更新 δ⁰_k = θ⁰_{k+1} − θ_k。
  - 定义前序足迹 u = ℓ_k(θ_k) − ℓ_k(θ_{k−1})，当前基足迹 d⁰ = ℓ_k(θ⁰_{k+1}) − ℓ_k(θ_k)。
  - 则 (1/N) uᵀd⁰ = δ_{k−1}ᵀ F̂_k δ⁰_k + O(η³)，即两个足迹的内积在经验输出 Fisher 下暴露了混合交互，且**仅需已有的前序足迹 u**。
- **回溯（Backtracking）路径解释**：
  - Γ(u,d) = −(1/N)uᵀd = (‖u‖² + ‖d‖² − ‖u+d‖²)/(2N)，正值表示步进运动被净位移抵消。
  - 分解为 Γ = Rev − Align；被控的**负到正回弹质量**定义为
    B⁻(u,d) = (1/N) Σ_{i: u_i<0} (−u_i)[d_i]₊（即前一步降低、下一步又升高的 token）。
- **历史条件化 PPO 惩罚（引理2）**：对修正 ξ_i ≤ 0，token 损失差满足 ∂(J^OSOL_i − J⁰_i)/∂z_i |_{z=0} = −ξ_i ≥ 0，即梯度下降会对提高所选 token 似然比施加惩罚。
- **残差到输出的符号传递（引理3）**：在局部自响应占优条件下（对角项 (K_E)_{ii}|ξ_i| ≥ Σ_{j≠i}(K_E)_{ij}ξ_j），修正足迹 h_i ≤ 0。
- **回溯收缩（命题1）**：若 h_i ≤ 0，则 ∆ctrl_k = B⁻(u,d⁰) − B⁻(u,d⁰+h) ≥ 0，且 B⁻(u,d^OSOL) ≤ B⁻(u,d⁰) − ∆ctrl_k + O(η³)。

### 2.3 算法流程（实现要点）

1. **焦点域调度**：训练步 k 从 D \ {f_{k−1}} 中均匀随机采样焦点域 f_k（禁止连续两步同一焦点）。
2. **基础系数**：A^base_i = c_i A^g_i，其中 c_i = w_{src(i)}/Z_k，焦点权重 w_f > 非焦点权重 w_nf，Z_k 为按 token 数加权的归一化因子。
3. **历史漂移与候选集**：对当前焦点域、且轨迹级 GRPO 优势非零的已实现响应 token，计算 u_i = log π_{θ_k}(a_i|x_i) − log π_{θ_{k−1}}(a_i|x_i)，候选集 C_k = {i : u_i < 0}。
4. **秩分配与自适应缩放**：
   - 按 u_i 升序排名，p_i = (rank₀(u_i)+1/2)/|C_k|，经截断仿射映射得 r̄_i ∈ [−1,0]（参数 (p_lo,p_hi,r_min,r_max)=(0.1,1,−1,0)），更负漂移惩罚更强。
   - κ_k = τ · std(A^base)/std(q)，r^OSOL_i = κ_k q_i，标准 τ=0.03，使残差标准差为基系数标准差的固定比例。
5. **最终系数与目标**：ẽA_i = clip(A^base_i + r^OSOL_i, −3, 3)，使用**未改动的 PPO 裁剪代理目标**优化；所有历史量均 stop-gradient，不引入辅助损失。

## 6. 主要结论与发现

- **诊断层面**：
  - 跨步回溯质量与后续任务损伤正相关（ρs = 0.40，95% bootstrap CI [0.05, 0.69]），而同点全局/模块诊断分别为 −0.19 和 −0.22（不能正向排序损伤）。
  - 前序 checkpoint 足迹对未来 token 回弹的排序优于 Hessian 代理：ROC-AUC 0.567 vs 0.498，平均精度 0.627 vs 0.579，top-5% 精确率 0.661 vs 0.551；非 token 级全局参考仅为 0.500。
  - 扩大 Hessian 参数覆盖只能小幅提升 ROC-AUC（0.508→0.534），却使显存从 26.6 GB 升至 43.5 GB；有限差分探针尺度 ϵ 还会显著改变所评估的输出空间位移。
- **优化层面**：
  - Qwen3-30B-A3B：OSOL 领域宏平均 **0.4822**，较最强基线 MGS（0.4560）提升 **5.7%**，且优于 CGPO（0.4528）；数学与代码最佳，Chat 第二，但 IF（0.1933）低于 RL 前基模型（0.2100）。
  - Qwen3-8B-Base：OSOL 领域宏平均 **0.3735**，较标准 GRPO 提升 6.4%，较最强基线 GRPO+KL 0.001（0.3700）仅提升 0.9%；数学最高，代码/IF/Chat 次高。
- **消融结论**：
  - 仅保留一步一导结构（去历史残差）得 0.3600，比完整方法低 0.0135（3.8%），说明焦点调度本身不足以解释增益。
  - 等权任务权重降至 0.1815（−51.4%），随机残差降至 0.1838（−50.8%），响应级（非 token 级）残差为 0.3640（低 2.6%）——证明焦点权重、漂移引导定位与 token 级分配三者缺一不可。

## 7. 优点

- **视角新颖且论证闭环**：把多域 RL 干扰从"同点一阶/曲率"重述为"相邻检查点输出空间混合交互"，并用定理1建立可观测性、用引理2/3与命题1完成"可观测→可控制"的理论链条。
- **无需显式高阶微分**：仅用已保存的前序 checkpoint 对同批 token 重打分，避免 Hessian/Fisher 的显式构造与显存开销，工程可落地性强。
- **与现有框架解耦
