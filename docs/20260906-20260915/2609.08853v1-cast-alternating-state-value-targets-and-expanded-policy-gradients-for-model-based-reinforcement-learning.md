## 摘要
基于模型的强化学习（MBRL）是一类学习环境模型并将其用于动作选择的强化学习方法，因其样本效率高而非常适合机器人领域。将学习到的模型与在线规划相结合可以进一步改进动作选择，因为规划器能够利用模型找到比仅靠学习策略更好的动作。近来将学习到的策略与在线规划相结合的方法通常学习策略的价值，而非更强的规划器引导行为的价值。我们提出 CAST（Critic with Alternating State-value Target，即具有交替状态值目标的评论家），它利用规划器引导行为来改进价值学习，同时用当前策略对价值估计进行正则化。CAST 用状态值评论家取代动作值评论家，其训练目标结合了真实的规划器引导转移和当前策略下的想象转移。由此得到的价值函数对应于规划器引导行为与当前策略之间的交替过程，使其能够受益于更强的规划器行为，同时受到正在学习的策略的正则化。我们在 DeepMind Control 和 HumanoidBench 套件上，将 CAST 与多种最先进方法进行比较评估，并展示了成功迁移到一台执行动态倒立的实体 Unitree Go2 四足机器人。

## Abstract
Model-based reinforcement learning (MBRL) is a family of RL methods that learn a model of the environment and use it for action selection, making it well suited to robotics due to its sample efficiency. Combining learned models with online planning can further improve action selection, as the planner can exploit the model to find better actions than the learned policy alone. Recent methods combining learned policies with online planning typically learn the value of the policy rather than the stronger planner-guided behavior. We present CAST (Critic with Alternating State-value Target), which uses planner-guided behavior to improve value learning while regularizing the value estimate with the current policy. CAST replaces the action-value critic with a state-value critic, trained using a target that combines a real planner-guided transition and an imagined transition under the current policy. The resulting value function corresponds to an alternating process between planner-guided behavior and the current policy, allowing it to benefit from the stronger planner behavior while being regularised by the policy being learned. We evaluate CAST on the DeepMind Control and HumanoidBench Suites against several state-of-the-art methods, and demonstrate successful transfer to a physical Unitree Go2 quadruped performing a dynamic handstand.

## 1. 核心问题与整体含义

- **研究背景**：基于模型的强化学习（MBRL）因样本效率高而适合机器人。将学习到的世界模型与在线规划结合（如 MPPI、TD-MPC2）可进一步改进动作选择，因为规划器通常能找到比学习策略 \(\pi_\theta\) 更好的动作。
- **核心问题**：现有“学习策略 + 在线规划”方法通常学习 \(\pi_\theta\) 的价值，而非更强的规划器引导行为 \(\beta\) 的价值。但 replay buffer 中的转移实际由 \(\beta\) 产生，策略更新却优化 \(\pi_\theta\)，存在分布不匹配。
- **关键观察**：行为策略 \(\beta\)（规划器增强策略）通常优于 \(\pi_\theta\)，尤其在训练早期，因此 critic 应更多学习 \(\beta\) 的价值，以提供更好的策略改进信号。
- **难点**：直接 bootstrap \(\beta\) 的价值会导致策略更新过大、训练不稳定；而学习 \(Q_\beta(z,a)\) 又需要频繁查询规划器，计算上不可行。
- **整体含义**：CAST 用状态值 critic 学习“规划器行为 \(\beta\) 与当前策略 \(\pi_\theta\) 交替”的价值，在利用更强规划器行为的同时，用当前策略进行正则化，为规划引导的 MBRL 提供了新的价值学习思路。

## 2. 方法论

- **基础框架**：CAST 构建在 TD-MPC2 上，保留其潜在世界模型、MPPI 规划器和策略先验。世界模型包括编码器 \(h_\xi\)、潜在动力学 \(d_\xi\)、奖励头 \(R_\xi\)，以及价值/策略网络。
- **从动作值到状态值**：
  - 将 TD-MPC2 的动作值 critic \(Q_\psi(z,a)\) 替换为状态值 critic ensemble \(V_\psi(z)\)。
  - 需要动作值时，用学习到的奖励和动力学模型重建一步动作值：
    \[
    \hat Q(z,a)=R_\xi(z,a)+\gamma \bar V_\psi(d_\xi(z,a))
    \]
  - 这样做避免为每个 TD 目标重新查询规划器 \(\beta\) 的动作分布。
- **规划器终端目标改变**：
  - 规划评分不再采样终端动作并评估 \(\bar Q\)，而是直接用状态值：
    \[
    \hat G=\sum_{h=0}^{H-1}\gamma^h R_\xi(z_{t+h},a_{t+h})+\gamma^H \bar V_\psi(z_{t+H})
    \]
- **混合价值目标**：
  - 每个 replay 转移 \((s_t,r_t,s_{t+1})\) 构造两步目标：
    \[
    y_t=r_t+\gamma\left[R_\xi(z_{t+1},\tilde a_{t+1})+\gamma \bar V_\psi(\tilde z_{t+2})\right]
    \]
    其中 \(z_{t+1}=h_\xi(s_{t+1})\)，\(\tilde a_{t+1}\sim\pi_\theta(\cdot|z_{t+1})\)，\(\tilde z_{t+2}=d_\xi(z_{t+1},\tilde a_{t+1})\)。
  - 该目标对应交替过程 \(\beta\to\pi_\theta\to\beta\to\pi_\theta\to\cdots\)。
- **理论分析**：
  - 定义 Bellman 算子 \(T_\beta\)、\(T_{\pi_\theta}\)，CAST 目标对应 \(T_{\text{CAST}}=T_\beta T_{\pi_\theta}\)。
  - 在固定策略、确定性动力学、可精确表示价值函数的假设下，\(T_{\text{CAST}}\) 是 \(\gamma^2\)-压缩，存在唯一固定点 \(V_{\text{CAST}}\)。
  - 展开后奖励按 \(\beta,\pi_\theta\) 交替折扣，使 \(V_{\text{CAST}}\) 介于 \(V_\beta\) 与 \(V_{\pi_\theta}\) 之间。
- **扩展策略梯度**：
  - 策略改进时，用重建的 \(\hat Q(z,\pi_\theta(z))\) 替代 \(Q_\psi(z,\pi_\theta(z))\)：
    \[
    \hat J_1(z;\theta)=R_\xi(z,\pi_\theta(z))+\gamma \bar V_\psi(d_\xi(z,\pi_\theta(z)))
    \]
  - 进一步将 \(\pi_\theta\) 在可微世界模型中展开 \(H_\pi\) 步：
    \[
    J_k(z_0;\theta)=\sum_{i=0}^{H_\pi-1}\gamma^i R_\xi(z^{(i)},a^{(i)})+\gamma^{H_\pi}\bar V_\psi(z^{(H_\pi)})
    \]
  - 默认 \(H_\pi=1\)，梯度通过 \(\pi_\theta\to R_\xi\to d_\xi\to\bar V_\psi\) 传播。
- **算法流程**：
  1. 用 MPPI 规划收集真实环境数据；
  2. 从 replay 采样，构造混合价值目标；
  3. 更新世界模型和状态值 critic；
  4. 用扩展策略梯度更新策略；
  5. Polyak 更新目标价值网络。
