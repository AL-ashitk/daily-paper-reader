## 摘要
异步强化学习已成为扩展语言模型训练的标准方式，但由此产生的策略滞后会使评论家偏向陈旧的行为策略。现有的异步LLM训练工作校正了演员，却未处理这一偏差；而经典强化学习中的离策略价值校正无法迁移到长时程智能体任务，因为较短的校正时域会使回归目标不含奖励，而较长的时域又会让重要性比值的乘积随轨迹长度呈指数漂移。我们提出BRACE，一种针对陈旧价值模型的锚定贝尔曼残差校正。BRACE将校正时域限制为策略token的一个前缀，并在其后锚定一个恒定权重的蒙特卡洛尾部，从而将策略校正与奖励传播分离。BRACE在BrowseComp-Plus上将mean@1较最强基线提升2.4%，每步运行速度比同步训练快2.46倍，并且在离策略下经过50次更新仍保持稳定。

## Abstract
Asynchronous reinforcement learning has become the standard way to scale training for language models, but the resulting policy lag biases the critic toward the stale behavior policy. Existing work on asynchronous LLM training corrects the actor and leaves this bias unaddressed, while the off-policy value correction of classical RL does not carry over to long-horizon agentic tasks, since a short correction horizon leaves the regression target free of the reward and a long one lets the product of importance ratios drift exponentially with the trajectory length. We propose BRACE, an anchored Bellman-residual correction for stale value models. BRACE bounds the correction horizon to a prefix of policy tokens and anchors a constant-weight Monte-Carlo tail beyond it, which separates policy correction from reward propagation. BRACE improves mean@1 on BrowseComp-Plus by $2.4\%$ over the strongest baseline, runs $2.46\times$ faster per step than synchronous training, and remains stable $50$ updates off-policy.

## 1. 核心问题与研究动机

- **异步 RL 的扩展性与新偏差**：异步强化学习将 rollout 生成与策略优化解耦，是扩展 LLM 训练的标准方式；但行为策略 \(\mu\) 会滞后于目标策略 \(\pi\)，形成 off-policy 问题。
- **现有修正集中在 actor 侧**：已有异步 LLM RL 工作多通过裁剪、信任域、mask 重要性比、重定义参考策略等方式修正 actor，但**没有处理 critic 回归目标本身的偏差**。
- **critic 会拟合陈旧行为策略**：由于 critic 的回归目标由 \(\mu\) 采样的轨迹构造，普通 GAE/回归会收敛到 \(V^\mu\)，而 actor 需要的是 \(V^\pi\)。于是优势 \(R - V^\mu(s_t)\) 带有系统性偏差 \(b(s_t)=V^\pi(s_t)-V^\mu(s_t)\)。
- **经典 V-trace 不适用于长时程 LLM 智能体任务**：
  - 若校正窗口太短，因终端奖励稀疏，窗口内不含 \(R\)，回归目标对奖励无直接依赖。
  - 若窗口太长以覆盖终端奖励，重要性比值乘积 \(\prod c_i\) 会随轨迹长度指数漂移，导致目标不稳定。
- **BRACE 的目标**：只修正 critic 的价值目标，将“策略校正”与“奖励传播”分离，从而在异步长时程任务中同时获得低偏差、低方差和训练稳定性。

## 2. 方法论：BRACE 的核心思想与算法

### 2.1 核心思想

BRACE 全称 **Anchored Bellman-Residual Correction**，即“锚定贝尔曼残差校正”。其关键设计是：

- **k-capped correction horizon**：只在当前状态之后的 \(k\) 个策略 token 内使用截断重要性权重修正 Bellman 残差。
- **anchored Monte-Carlo tail**：在 \(k\) 步之后不再逐 token 加权，而是给尾部一个恒定权重 1，使其望远镜化为终端奖励 \(R\)。
- 这样，终端奖励总能进入目标，同时重要性乘积不会随剩余轨迹长度指数增长或衰减。

### 2.2 关键符号与公式

令：
- \(w_t=\pi(a_t|s_t)/\mu(a_t|s_t)\)
- \(\rho_t=\min(\bar\rho,w_t)\)
- \(c_i=\lambda\min(\bar c,w_i)\)
- \(\delta_t^V=\rho_t(r_t+\gamma V(s_{t+1})-V(s_t))\)
- \(j=\min(s+k,T)\)
- \(\Pi_k(s)=\prod_{i=s}^{j-1}c_i\)

BRACE 的价值目标可写为：

\[
V^{\text{BRACE}}_{\text{targ}}(s_s)
=
V(s_s)
+
\sum_{t=s}^{T}
\gamma^{t-s}
\left(
\prod_{i=s}^{\min(t,s+k)-1}c_i
\right)
\tilde\rho_t^{(s)}
\left(
r_t+\gamma V(s_{t+1})-V(s_t)
\right)
\]

其中：

\[
\tilde\rho_t^{(s)}=
\begin{cases}
\rho_t, & t<j\\
1, & t\ge j
\end{cases}
\]

等价地，可重写为“校正窗口 + 锚定收益”：

\[
V^{\text{BRACE}}_{\text{targ}}(s_s)
=
V(s_s)
+
\sum_{t=s}^{j-1}
\gamma^{t-s}
\left(\prod_{i=s}^{t-1}c_i\right)
\delta_t^V
+
\Pi_k(s)
\left[
\gamma^{T-s}R-\gamma^{j-s}V(s_j)
\right]
\]

其含义是：
- 前 \(k\) 步用截断重要性权重做策略校正；
- 尾部用恒定权重 1 使残差望远镜化，最终携带终端奖励 \(R\)；
- 终端奖励系数仍为 \(\gamma^{T-s}\Pi_k(s)\)，不会被尾部加权破坏。

### 2.3 算法流程

1. 用行为策略 \(\mu\) 生成轨迹，并记录采样 log 概率 \(\log\mu(a_t|s_t)\)。
2. 在当前 actor 上重新计算 \(\log\pi_\theta(a_t|s_t)\) 与 critic 值 \(V_\phi(s_t)\)。
3. 计算 token 级重要性比 \(w_t\)、截断权重 \(\rho_t\)、trace 权重 \(c_i\) 和残差 \(\delta_t^V\)。
4. 对每个位置 \(s\)，计算 \(j=\min(s+k,T)\) 与 \(\Pi_k(s)\)，构造 BRACE 目标 \(V^{\text{BRACE}}_{\text{targ}}(s_s)\)。
5. critic 使用带 value clip 的平方误差损失回归该目标。
6. 计算优势 \(\hat A_s=r_s+\gamma V^{\text{BRACE}}_{\text{targ}}(s_{s+1})-V(s_s)\)。
7. actor 使用标准 PPO clipped objective 更新。

### 2.4 理论性质

- 窗口内残差满足 \(E_\mu[\rho_t\delta_t|s_t]=0 \iff V=V^{\pi_{\bar\rho}}_\gamma\)，其中 \(\pi_{\bar\rho}(a|s)\propto \min(\bar\rho\mu(a|s),\pi(a|s))\)。
- 尾部无权重残差满足 \(E_\mu[\delta_t|s_t]=0 \iff V=V^\mu_\gamma\)。
- 因此 \(k\) 控制校正深度：\(k\) 越大越接近 \(V^{\pi_{\bar\rho}}\)，但权重乘积方差越大；\(k\) 越小越接近 \(V^\mu\)，但更稳定。
- 该设计避免了 V-trace 在长时程稀疏奖励下的“覆盖 vs 控制”冲突。

所有基线都只修正 actor，不修正 critic target：

- **PPO**：仅使用 clipped surrogate。

- **AReaL**：将信任域锚定在更新前参数而非采样策略。
- **KPop**：基于 Bernoulli 散度过滤训练/推理引擎不一致的 token。
