## 摘要
基于正则化的方法已成为训练深度强化学习策略以抵御对抗性输入扰动的标准方法。在本文中，我们通过推导标称策略与最坏情况策略之间性能差距的新上界，统一了这些方法。每个上界均可表示为现有正则化目标加上标称策略与最坏情况策略之间的 KL 散度惩罚，这进一步解释了为何在实践中添加 KL 惩罚能够提高鲁棒性。基于这些上界，我们将鲁棒训练建模为约束优化问题，表明现有方法对应于固定拉格朗日乘子的特例。相反，我们与策略联合更新乘子，以自动调整正则化权重。最后，我们在多个连续控制任务上进行了广泛的对抗性评估，以验证我们的理论分析。

## Abstract
Regularization-based methods have become a standard approach for training Deep Reinforcement Learning policies against adversarial input perturbations. In this paper, we unify these methods by deriving new upper bounds on the performance gap between the nominal and worst-case policies. Each upper bound is expressed as an existing regularization objective plus a KL-divergence penalty between the nominal and worst-case policies, which further explains why adding a KL penalty improves robustness in practice. Building on these bounds, we formulate robust training as a constrained optimization problem, showing that existing methods correspond to the special case of a fixed Lagrange multiplier. We instead update the multiplier jointly with the policy to automatically tune the regularization weight. Finally, we conduct extensive adversarial evaluations across several continuous control tasks to validate our theoretical analysis.

## 1. 核心问题与整体含义

- **研究背景**：深度强化学习（DRL）策略在输入状态受到微小对抗性扰动时，性能可能急剧下降。例如传感器噪声或人为攻击可导致策略失效。
- **现有方法的两大流派**：
  - **基于正则化的方法**：在训练目标中加入鲁棒性项，即 `L_DRL(π) + λ·L_robust(π)`，无需额外采集轨迹，样本效率更高。代表方法有 SA-Reg、Radial、WocaR-RL。
  - **攻击驱动的方法**：在对抗扰动轨迹上训练，需额外采集轨迹，样本效率较低。
- **核心痛点**：
  1. 三种正则化方法各自基于不同理论推导，**缺乏统一解释**；
  2. 实践中发现将 SA-Reg 与 Radial 或 WocaR-RL 组合能稳定提升鲁棒性，但**原因不明**；
  3. 正则化权重 λ 需通过昂贵的超参数搜索确定，且**训练中固定不变**。
- **整体含义**：本文旨在为基于正则化的鲁棒 RL 提供统一的理论框架，并据此提出自动调节正则强度的方法。

## 2. 方法论

### 2.1 核心思想

- 通过推导标称策略 π 与最坏情况策略 π_wc 之间性能差 `J(π) − J(π_wc)` 的**新上界**，将三种正则化方法统一为：
  > **性能差上界 = 现有正则化目标 + KL/TV 散度惩罚项**
- 这解释了为何添加对抗性 KL 惩罚在实践中有效——它天然出现在所有上界中。

### 2.2 关键技术细节

- **修正 SA-Reg 常数**：原论文常数因遗漏因子 `1/(1−γ)` 有误，本文修正为：
  - `α_R = 2·max|R(s,a,s')| / (1−γ)²`
  - 并将状态上的 max 改为关于 d_π 的期望，与实现一致。
- **三个统一上界定理**：
  - **定理 2（SA-Reg）**：性能差 ≤ `α_R · E[DTV(π‖π_wc)]`
  - **定理 3（Radial）**：性能差 ≤ `−1/(1−γ)·E[A^π(s,a)] + α_A·E[DTV(π‖π_wc)]`，其中第一项即 Radial 目标，第二项即 SA-Reg 惩罚，从而解释了二者组合的增益。
  - **定理 4（WocaR-RL）**：将 WocaR-RL 重写为最坏情况优势函数期望 `E[A^π_wc(s,a)]`，性能差 ≤ `−1/(1−γ)·E[A^π_wc] + 2α_R·E[DTV]`。
- **从 d_π 到 d_πk 的转换**：引入三角不等式，使上界仅依赖当前策略 π_k 采集的样本，便于实际估计。

### 2.3 鲁棒性作为约束（RaC 框架）

- **核心转变**：将鲁棒训练建模为约束优化问题：
  > `π_{k+1} = argmax J(π)  s.t. J_wc(π) ≥ d 且 D(π,π_k) ≤ δ`
- **拉格朗日松弛**：`max_π min_{λ≥0} [J(π) − λ(C(π) − Δ_max)]`
- **关键洞察**：现有正则化方法等价于**固定拉格朗日乘子 λ** 的特例；本文改为与策略联合更新 λ，实现**自适应正则权重**。
- **三种约束变体**：
  - **RaC-Mono**：约束最坏情况性能单调提升（d = J_wc(π_k)），使用定理 5 的下界作为替代。指出若用固定系数求解，即恢复原 WocaR-RL。
  - **RaC-SA**：约束性能差不超过 `Δ_max = η·|J(π_k)|`，用定理 2 的上界作为替代。
  - **RaC-Radial**：同上，但用定理 3 的上界。
- **实现修正**：
  1. 用当前 batch 内最大值替代全局 max 常数；
  2. 引入梯度平衡系数 `β = ‖∇J(π)‖ / ‖∇C(π)‖`，使两项梯度量级可比（借鉴 Stooke 等 2020）。

## 6. 主要结论与发现

1. **理论统一**：三种正则化方法（SA-Reg、Radial、WocaR-RL）均可写成性能差上界，且**都包含 SA-Reg 的 TV 散度惩罚项**，从理论上解释了组合使用能提升鲁棒性。
2. **原论文常数修正**：指出 SA-Reg 原上界常数存在遗漏 `1/(1−γ)` 的错误。
3. **约束视角**：现有正则化方法等价于固定拉格朗日乘子；本文的 RaC 方法可自动调节 λ。
4. **性能表现**：
   - **RaC-SA 与 RaC-Radial 达到 SOTA**，在所有环境和攻击下整体最优。
   - **RaC-SA 在每个环境下均优于 SA**；RaC-Radial 除 HalfCheetah 的两个攻击外均优于 Radial-SA。
   - **WocaR-RL 和 RaC-Mono 未能学到鲁棒策略**，表明"最坏情况性能单调提升"这一目标本身提供的归纳偏置不足。
5. **η 敏感性**：η = 20% 是唯一在三个环境下都保持可接受性能的设置；η = 10% 或 50% 至少在一个环境中导致灾难性性能。
6. **代价可控**：RaC 方法仅增加约 0.5 小时训练时间，但鲁棒性提升显著，性价比高。
